swordbot privacy policy

Last updated: October 1, 2026

swordbot is a personal assistant that its owner runs for their own use. It helps the owner email merchants' customer support about problems with online orders. It only responds to the owner's Telegram account and only connects to the owner's Gmail account.

Google user data

swordbot requests two Google permissions:

  • https://www.googleapis.com/auth/gmail.send lets it send email from the owner's Gmail account.
  • https://www.googleapis.com/auth/gmail.readonly lets it search and read the owner's mailbox. It cannot change or delete anything in it.

Sending. It sends an email only after the owner has reviewed that exact email (recipient, subject and text) and approved it by pressing a Send button. After a send, it keeps the message and thread identifiers Gmail returns, so the owner can see what was sent.

Reading. When the owner reports a problem with an order, swordbot searches the mailbox for that merchant's order emails from around the order date, to find the receipt. It reads at most a few of the best matches, never the mailbox as a whole. Each of those emails is reduced by swordbot's own code to its visible text, and that text is sent once to OpenAI to pick out the order number, date, total, items and any customer-support address. The owner is then shown those details and asked whether it is the right order. Only if the owner says yes are they kept, together with the Gmail identifier of the email they came from. The email's text itself is not stored and not logged. swordbot also looks up, by its identifier, an email it sent itself, to confirm that the send went through.

swordbot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

What is stored

swordbot stores, in its own database: the owner's chat messages about each problem, the details of each case (such as the merchant, order number, order date, total, items and the resolution wanted, each marked with where it came from), the email drafts, and the emails sent. Emails read from the mailbox are not stored. The Google access credential is kept as a secret on the server running swordbot and is never logged.

Who else processes the data

  • Telegram carries the chat between the owner and swordbot.
  • OpenAI receives the chat messages, the case details and the trimmed text of the few order emails described above through its API, to help understand the problem, find the order and draft the email, under OpenAI's API data policies.
  • Google (Gmail) delivers the emails the owner approves and answers the mailbox searches.
  • The hosting provider that runs swordbot's server and database.

The data is not sold, not used for advertising, and not shared with anyone else.

Revoking access and deleting data

Google access can be revoked at any time at myaccount.google.com/permissions. swordbot then cannot send or read anything. The owner can delete swordbot's stored data by deleting its database.

Changes

If swordbot starts using more Google data (for example, following the replies to the emails it sent), this policy will be updated before that happens.
