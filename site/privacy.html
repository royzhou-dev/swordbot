swordbot privacy policy

Last updated: September 27, 2026

swordbot is a personal assistant that its owner runs for their own use. It helps the owner email merchants' customer support about problems with online orders. It only responds to the owner's Telegram account and only connects to the owner's Gmail account.

Google user data

swordbot requests one Google permission: https://www.googleapis.com/auth/gmail.send, which lets it send email from the owner's Gmail account. It cannot read, search, change or delete anything in the mailbox.

It sends an email only after the owner has reviewed that exact email (recipient, subject and text) and approved it by pressing a Send button. After a send, it keeps the message and thread identifiers Gmail returns, so the owner can see what was sent.

swordbot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

What is stored

swordbot stores, in its own database: the owner's chat messages about each problem, the details of each case (such as the merchant, order number, order date, items and the resolution wanted), the email drafts, and the emails sent. The Google access credential is kept as a secret on the server running swordbot and is never logged.

Who else processes the data

  • Telegram carries the chat between the owner and swordbot.
  • OpenAI receives the chat messages and case details through its API to help understand the problem and draft the email, under OpenAI's API data policies.
  • Google (Gmail) delivers the emails the owner approves.
  • The hosting provider that runs swordbot's server and database.

The data is not sold, not used for advertising, and not shared with anyone else.

Revoking access and deleting data

Google access can be revoked at any time at myaccount.google.com/permissions. swordbot then cannot send anything. The owner can delete swordbot's stored data by deleting its database.

Changes

If swordbot starts using more Google data (for example, reading order receipts), this policy will be updated before that happens.
